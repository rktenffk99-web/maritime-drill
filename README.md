## v5.36 저장된 시험 개별 삭제

- 이어풀기 카드 오른쪽 위에 `×` 버튼을 추가했습니다. 확인 후 해당 시험의 저장된 답안·문항 순서·이어풀기 위치만 삭제하며, 다른 시험과 이미 기록된 성적·복습 진도는 그대로 둡니다.
- 같은 시험을 다른 기기에서 동시에 푼 충돌 버전이 있으면 확인창에 안내하고 모두 삭제합니다. 삭제 표시를 저장하지 못하면 기존 시험을 유지하고, 삭제 정보는 Google Drive의 기존 삭제 표시 체계로 동기화합니다.
- 사용자 조작으로 삭제가 완료되면 현재 화면에서 해당 카드가 사라집니다. 삭제는 취소할 수 없으며, 다른 기기의 목록에도 동기화 후 반영됩니다.
- 여러 탭의 답안 저장이 겹쳐도 삭제한 시험이 다시 살아나지 않도록 시험 ID별 삭제 표시를 별도로 보존합니다. 이어풀기 로딩 중 선택한 저장본이 삭제되거나 바뀌면 해당 시험을 열지 않으며, 사용자가 이동한 새 화면을 뒤늦게 덮지 않습니다.
- 검증: `node tools/test_exam_deletion_v536.js`, `python tools/browser_exam_deletion_v536.py`. 취소·삭제·저장 실패·완전 종료 후 재접속과 동시 저장을 격리된 시험 기록으로 확인하며, 실제 사용자의 시험 기록은 변경하지 않습니다.

## v5.35 문제 순환·저장 시스템 점검

- 오늘 숙제 끝부분에서 다음 날 재확인 예약의 저장이 실패하면 현재 답안과 체크포인트를 유지합니다. 저장 재시도·재접속·홈 이동에서도 예약을 다시 확인하며, 같은 답안을 중복 채점하지 않습니다.
- 다른 기기에서 별개 문항을 나중에 풀어도 기존 문항의 최신 오답·숙련 상태를 과거 값으로 되돌리지 않습니다. 문항별 변경 시각과 전체 체크포인트의 저장 시각을 구분합니다.
- 학습 값 저장 후 동기화 변경 시각 저장이 실패하면 원래 값을 복원하고 저장 실패를 표시합니다. 삭제·최초 저장도 같은 기준을 적용합니다.
- 원격 기록 적용 후 최종 동기화 상태 저장이 실패하면 적용 전 기록으로 되돌립니다. 값 적용 중 예외도 같은 방식으로 처리하고, 복구가 불완전하면 복구 지점을 보존합니다.
- 시험 준비 중 중복 시작·급수 변경·화면 이동을 막고 Drive의 원격 적용을 미룹니다. 문제 다운로드 실패 시 시험 목록으로 돌아갈 수 있는 오류 화면을 표시합니다.
- 검증에는 신규 오류 재현 검사와 기존 문제 배분·중복 방지·복습 순환, 저장/복원/동기화 검사를 포함합니다. 시험별 50문항 풀이 후 브라우저 종료·재접속·채점 및 전체 13개 면허 문제은행 로딩 검사도 수행합니다. 자동화 CI에 시험별 저장과 전체 앱 브라우저 검사도 추가했습니다.

## v5.34 모의고사 해설 바로 보기

- 모든 필기 모의고사(통합 모의시험 포함)에서 `0` 또는 숫자패드 `0`, 혹은 `해설 보기 (0)` 버튼을 누르면 **현재 문항의 정답과 전체 해설**을 즉시 확인할 수 있습니다. 다시 누르면 닫힙니다.
- 기존 `힌트 보기 (0)` 버튼은 제거했습니다. 문제를 바꿀 때 해설은 자동으로 닫히며, 해설만 열었다고 선택 답안이나 진행 위치가 바뀌지 않습니다.
- 해설을 열기 **전에** 도움 사용 기록을 시험별 체크포인트에 저장합니다. 저장에 실패하면 정답과 해설을 공개하지 않습니다. 열람한 시험은 최근 실력 평균에 포함하지 않으며, 기기 간 이어풀기에도 해당 기록이 유지됩니다.

## v5.33 전체 점검: 저장 실패와 Drive 복구 보호

- 오늘 공부 답안의 저장이 실패하면 현재 문제와 답안을 화면에 유지하고, 저장 재시도 안내를 표시합니다. 다음·이전 문제 이동, 완료와 화면 이탈도 저장 결과를 확인하며 재시도로 학습 횟수를 중복 계산하지 않습니다.
- 평가시험의 정답·해설은 도움 사용 기록을 먼저 저장한 뒤 공개합니다. 기록을 저장할 수 없으면 해설을 공개하지 않고 재시도를 안내합니다.
- 최초 연결 경쟁으로 Drive 통합 백업이 여러 개 생겼을 때 모든 백업을 읽어 병합합니다. 새 기기도 다른 기기에만 있던 학습 기록을 복원할 수 있습니다.
- 일반 진도·오답·성적도 공통 백업을 갱신하기 전에 기기별 백업에 저장합니다. 동시 업로드 후 두 기기가 모두 종료되어도 기록을 다시 모을 수 있습니다. 같은 브라우저의 여러 탭은 Web Locks로 동기화를 직렬화하며, 이 기능이 없는 환경에서는 로컬 저장을 유지하고 클라우드 동기화 제한을 알립니다.
- 로그인 정보가 갱신되거나 다른 탭에서 바뀌면 진행 중이던 요청을 중단합니다. 이전 연결의 파일·업로드를 새 로그인 정보로 재전송하지 않고 새 동기화에서 다시 확인합니다.
- Drive 데이터의 형식과 시험 기록의 날짜를 적용 전에 검증합니다. 손상된 원격 기록으로 정상 진도를 덮거나, 잘못된 시험 날짜 한 개로 홈 화면 전체가 중단되는 일을 방지합니다. 잘못된 로컬 시험 원본은 삭제하지 않습니다.
- 명시적인 백업 복구 후 재로딩에는 이전 화면의 자동저장이 개입하지 않도록 하여, 복구 직후 답안이 다시 바뀌는 일을 막습니다.
- 검증: `TZ=UTC bash tools/check_app.sh`, `python tools/browser_app_audit_v533.py` 및 기존 브라우저 회귀 검사로 숙제 저장 실패·재시도, 시험 종료·재접속·채점, 메뉴·모바일 화면·백업 복구를 확인합니다. 실제 계정의 데이터에 실패를 주입하지 않습니다.

## v5.32 명시적 시험 복구와 Drive 첫 동기화

- ‘이전 상태로 되돌리기’와 파일 백업 가져오기로 복구한 진행 중 시험은 새 시험 번호를 받습니다. 문제 순서·선택지·답안·중단 위치·힌트를 유지하고, 동시 수정된 답안은 각각 보존합니다. 이전 번호에 남은 삭제 표시나 완료 기록이 복구한 답안을 다시 없애지 않습니다. 파일 가져오기는 기존 시험을 덮어쓰지 않고 복구본을 별도 시험으로 추가합니다.
- 완료된 시험은 최소 완료 정보로 유지합니다. 복구 중 저장 실패가 발생하면 시험 데이터와 동기화 상태, 복구 지점을 함께 원상복구합니다.
- Drive 통합 백업이 없거나 다운로드 시 404로 확인되면, 남아 있는 시험별 파일과 삭제 표시부터 병합한 뒤 통합 백업을 다시 만듭니다. 첫 동기화에서 바로 복원하며 인증·권한·네트워크 오류는 파일 없음으로 처리하지 않습니다.
- 검증: `TZ=UTC bash tools/check_app.sh`, `node tools/test_exam_restore_v532.js`, `python tools/browser_exam_sessions_v530.py`. 파괴적인 복구·삭제 시나리오는 실제 계정 기록 대신 격리된 테스트 저장소에서 재현합니다.

## v5.31 시험 기록 정리와 삭제 동기화

- 시험 삭제 표시는 해당 시험 ID의 최종 상태로 취급합니다. Drive에 별도 삭제 표시를 먼저 저장하므로, 오래된 기기가 통합 백업을 덮어써도 삭제한 시험이 다시 나타나지 않습니다. 삭제한 시험은 같은 ID로 재개하지 않고 새 시험으로 시작합니다.
- 채점 완료된 버전은 시험 ID·완료 시각·충돌 판별용 버전 정보만 남깁니다. 문제 원문과 답안 배열을 제거하며, v5.30 완료 기록도 앱 시작 시 정리합니다. 다른 기기에서 동시에 풀던 버전이 있으면 그 답안과 시험지는 보존합니다. 성적 기록은 별도로 유지됩니다.
- 답안·문제 위치·힌트 상태가 바뀌지 않은 저장·화면 갱신·파일 백업은 새 답안 버전이나 Drive 파일을 만들지 않습니다. 학습 시간은 다음 실제 변경 시 함께 저장됩니다.
- 추가 검증: `node tools/test_exam_cleanup_v531.js`, `node tools/test_drive_exam_journal.js`. 실제 브라우저 검사는 기존 50문항 복원·시험 전환·채점 검사에 완료 기록 크기와 중복 저장 검사를 포함합니다. 실제 Google 계정 인증 대신 모의 Drive 서버로 충돌·재시도·삭제 표시 복구를 검증합니다.

## v5.30 시험별 독립 저장과 정확한 이어풀기

- 새 시험마다 고유 ID와 별도 저장 키를 사용합니다. 여러 시험을 시작해도 각각의 답안·중단 위치가 남습니다. 이어풀기 목록에서 급수, 시험 종류, 시작 시각, 응답 수, 시험 번호를 확인해 선택합니다.
- 시험지 순서와 문항·선택지·정답 내용을 검증한 뒤 답안과 힌트를 복원합니다. 원문이 변경되거나 선택한 저장본을 찾지 못하면 다른 시험으로 대체하지 않습니다.
- v5.29의 공용 이어풀기 데이터는 읽지 않습니다. 기존 성적과 일반 학습 기록은 유지합니다. 새 시험부터 v3 저장 형식을 사용합니다.
- 같은 시험을 다른 기기/탭에서 따로 풀면 인과 관계를 비교하여 순차적인 진행은 최신 버전으로, 충돌한 답안은 별도 버전으로 보존합니다. 채점 완료도 버전으로 저장해 오래된 동기화가 완료 전 답안을 되살리지 않습니다.
- Drive에는 변경된 시험 버전을 덮어쓰지 않는 별도 파일로 먼저 저장합니다. 두 기기가 기존 통합 백업 파일을 동시에 갱신해도 시험 기록을 다시 병합할 수 있습니다. Drive 시험 파일은 자동 삭제하지 않으므로 장기 사용 시 계정 저장 공간을 사용합니다. 파일 업로드나 다운로드 실패 시 로컬 기록을 유지하고 다음 동기화에 재시도합니다.
- 검증: `TZ=UTC bash tools/check_app.sh`, `python tools/browser_exam_sessions_v530.py`, `python tools/browser_response_speed.py`. 브라우저 검사는 Playwright/Chromium이 필요합니다. Drive 충돌 검사는 인증된 개인 계정을 변경하지 않는 모의 서버 테스트입니다.

## v5.29 입력 반응속도 개선

- 답 선택·다음 문제 이동 때 같은 시험지의 글자와 수식을 반복 보정하던 작업을 줄였습니다. 원문 내용이 바뀌거나 새 기출이 로드되면 다시 보정하며 문항 검증은 유지합니다.
- 답안 저장 시 변경한 항목의 동기화 메타데이터만 펼치고 압축합니다. 관련 없는 학습 기록의 동기화 메타데이터를 매번 재처리하지 않습니다.
- 답안·현재 위치·힌트 사용 기록은 계속 즉시 저장합니다. 저장 실패 보호, 다른 기기 기록 병합, 기존 신고 문항 정정을 회귀 검사합니다.
- 실제 키 입력부터 화면 갱신까지의 반응과 30,000개 동기화 메타데이터가 있는 조건을 브라우저 검사에 추가했습니다.

## v5.28 모의시험 힌트 (v5.34에서 해설 보기로 대체)

- v5.28에서는 숫자 `0` 또는 숫자패드 `0`으로 풀이 힌트를 열고 닫았습니다. v5.34부터 같은 단축키로 정답·전체 해설을 열고 닫습니다.
- 과거의 일반적인 풀이 안내·지문 용어 힌트 기능은 현재 모의고사 화면에서는 제공하지 않습니다.
- 힌트 사용 문항을 자동저장해 이어풀기·Drive 동기화에도 보존합니다. 힌트를 본 시험은 이번 점수를 표시하되 최근 평균에서 제외하고, 도움을 받아 맞힌 문항은 불확실한 학습 기록으로 반영합니다.
- 입력창·신고창에서는 단축키를 실행하지 않으며, 키를 길게 눌러도 힌트가 반복해서 열리고 닫히지 않습니다.

## v5.27 추가 점검과 편의성 개선

- 년도별 출제에서 현재 선택한 상선·어선 구분을 사용하고, 면허 변경 후 맞지 않는 필터가 남아 빈 목록이 되는 문제를 수정했습니다.

## v5.26 오류 수정

- 늦게 불러오는 기출과 섞인 선택지에도 PDF 쪽번호 정리를 적용합니다. 2026-10-26 확인한 신고 8건(6문항)을 회귀 검사에 포함했습니다. 정답과 정상적인 수식·음수는 유지합니다.
- 신고 저장·복사·삭제가 실패하면 성공으로 표시하지 않습니다. 저장 실패 시 입력창과 기존 신고를 유지하며, 500건을 넘길 때 오래된 신고를 자동 삭제하지 않습니다.
- Drive 동기화에서 모의시험 회차별 점수와 다른 기기의 신고를 합칩니다. 최근 기출 점수는 해당 회차의 문항수와 함께 보존하고, 도판 훈련 도중에는 원격 기록 적용을 미룹니다.
- 답안·진도·점수 저장이 모두 성공해야 제출을 완료합니다. 저장 실패 시 변경된 채점 기록을 되돌리고 복구 답안을 유지하며, 재시도로 풀이 횟수가 중복 증가하지 않도록 합니다.

## v5.22 학습 정책

- 문항은 지문·선지·정답 내용으로 구분합니다. 기존 대표 문항의 진도 키는 고정하고 다른 선지 변형에는 새 키를 부여합니다. 기존 저장 기록을 지우지 않습니다.
- 시험 당일을 신규 학습 가능일에서 제외하고, 설정된 시험 직전 기간은 복습 여유로 계산합니다. 상한 때문에 목표가 부족하면 보장 문구 대신 부족량을 표시합니다.
- 기본 문항 상한과 추가 재확인 풀이 횟수를 나누어 표시합니다. 복습·신규·과목 배분을 한 번에 결정하고 최종 배정으로 지표를 계산합니다.
- 최근의 독립적인 회상 성공과 오답 후 회복 상태를 복습 간격에 반영합니다. 과거 누적 정답·오답 통계는 유지합니다.
- 예측 모의는 문항별 가중치로, 평가 모의는 적게 노출된 문항을 우선하여 추첨합니다. 모든 모의고사에서 원할 때 정답과 전체 해설을 열 수 있으며, 해설을 본 평가는 독립적인 실력 평균에서 제외합니다. 같은 선택 과목 구성끼리 평균을 냅니다.
- 추가 분석 증거는 문항당 최근 3개·전체 최근 400개로 제한합니다. 누적 통계와 실제 복습 날짜를 보존하면서 기본값과 로컬 동기화 메타데이터의 저장량을 줄입니다.
- 이 정책의 배분 비율과 간격은 명시적인 운영 규칙이며 학습 효과나 합격률의 최적값을 뜻하지 않습니다.

문항 분리·복원으로 전체 학습 단위 수가 늘 수 있습니다. 이는 기록 초기화가 아니라 이전에 묶이거나 제외된 문항을 독립적으로 학습하도록 바뀐 결과입니다. 과거의 범위 불명 평가 점수는 보존하되 새로운 범위별 평균에 섞지 않습니다.

브라우저 LocalStorage의 절대 용량 한도는 남습니다. 누적된 진도와 전체 복구 사본 등 많은 데이터를 함께 보관하면 한도를 넘을 수 있습니다. 용량 확보를 위해 기존 진도나 복구 사본을 자동으로 삭제하지 않으며, 저장 실패 시 기존 값을 보존하고 알립니다.
